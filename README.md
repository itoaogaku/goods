# goods

青学駅伝グッズの在庫・販売データを管理するプロジェクトです。**アスリートキャリアセンター**（水上村・町田の在庫）と**陸上部**（ACCから仕入れて販売・購買会卸し・プレゼントする在庫）を、別々のNotionデータベース・別々のダッシュボードタブで管理します。

## 構成

| ディレクトリ | 役割 |
| --- | --- |
| [`migration/`](./migration) | Wixの注文データ（CSVエクスポート or eコマースREST API）をNotionデータベースへ移行するCLIツール（Node.js / TypeScript） |
| [`web/`](./web) | Notionのデータを集計・登録するAPI（Route Handlers）と、ACC / 陸上部それぞれのダッシュボード画面を持つNext.jsアプリ。Vercelへデプロイ |

## データフロー

```
Wix Stores（水上村からの注文）
   │  初回のみ: CSVエクスポート or eコマースREST API
   │  以降: web/ が30分ごとに自動取り込み（app/api/acc/sync-wix, Vercel Cron）
   ▼
migration/ (CLI, 初回のみ) ─▶ Notion: ACCデータベース ◀── web/ の在庫登録・拠点間移動・
                            │                        手入力販売フォーム（水上村/町田）
                            │
                            │  （ACC→陸上部の卸しはACC側の記録から自動反映）
                            ▼
                    Notion: 陸上部データベース ◀── web/ の在庫登録・拠点間移動・
                            │                        手入力販売フォーム（陸上部/購買会）
                            ▼
              web/ Next.js API (app/api/[ledger]/*)
                            │
                            ▼
        web/ ダッシュボード（"/" = ACC タブ、"/track-team" = 陸上部タブ）
```

両データベースは同じスキーマ（取引ID・明細ID・種別・日時・拠点・移動先拠点・商品名・数量・単価・合計金額・備考・ステータス）を使い、`種別`で入庫・通常販売・関係者価格販売・プレゼント・拠点間移動・陸上部卸し（ACC台帳のみ）・購買会卸し（陸上部台帳のみ）・棚卸調整を区別します。詳細は `web/README.md` の「在庫・販売管理の仕組み」を参照してください。

## はじめに

1. `migration/README.md` の手順でACC用Notionデータベースを作成し、Wixの注文データ（水上村分）を移行します
2. 同じ手順で陸上部用のNotionデータベースも作成します（`web/README.md` 参照）
3. `web/README.md` の手順で環境変数を設定し、ダッシュボードをローカル起動またはVercelへデプロイします
4. 商品完成時の在庫登録、拠点間移動、町田・関係者価格・プレゼント・卸しなどの手入力は、ダッシュボード上のフォームから行います
